# 🍔 Stellar Burgers

Космический конструктор бургеров. Собирай бургер из булок, начинок и соусов, оформляй заказ и следи за его статусом в реальном времени. Pet-проект на React, сделанный для души (и заодно для прокачки навыков).

## ✨ Возможности

- 🔧 Конструктор бургера: перетаскивай ингредиенты, меняй порядок, добавляй в два клика
- 🧮 Живой подсчёт стоимости и пищевой ценности в процессе сборки
- 📢 Лента заказов всех пользователей + история собственных заказов в личном кабинете (WebSocket)
- 👤 Авторизация и регистрация, восстановление пароля, защищённые маршруты
- 🔍 Детальный просмотр ингредиентов и заказов в модалках с роутингом

## 🛠 Стек

- **React 18** + **TypeScript**
- **Redux Toolkit** + thunk для state-менеджмента
- **React Router v6**
- **WebSocket** для live-обновления ленты заказов
- **Jest** + **Testing Library** для unit-тестов, **Playwright** и **Cypress** для e2e
- Storybook для разработки UI-компонентов

## 🚀 Запуск

```bash
# установка зависимостей
npm install

# запуск дев-сервера (webpack-dev-server)
npm start
```

> ⚙️ Для работы с API нужна переменная окружения `BURGER_API_URL`. Ссылка на сервер лежит в `.env.example` — скопируй себе в `.env`.

## 🧪 Тесты

```bash
npm test                # unit-тесты (Jest)
npm run test:playwright # e2e-тесты (Playwright)
```

## 🎨 Другие команды

```bash
npm run lint        # eslint
npm run storybook   # UI-кит
```

## 📂 Структура

```
src/
├── components/   # UI-компоненты (модалки, карточки, конструктор)
├── pages/        # страницы (конструктор, лента, профиль, авторизация, 404)
├── services/     # redux store, слайсы и работа с API
└── utils/        # хелперы и burger-api
```
